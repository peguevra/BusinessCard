■ 名刺管理システム 使い方（Supabase版・最終）

━━━━━━━━━━━━━━━━━━━━
■ 概要
━━━━━━━━━━━━━━━━━━━━

PDFをフォルダに入れるだけで、

・Google Driveへアップロード
・Supabaseへ登録（※正本）
・CSV生成（スナップショット）

までを自動で行う。

iPhoneからはSupabase経由で一覧閲覧可能。

━━━━━━━━━━━━━━━━━━━━
■ 設計思想（最重要）
━━━━━━━━━━━━━━━━━━━━

Supabaseが唯一の正本

CSV = スナップショット
JSON = 表示用データ
Drive = ファイル保存

つまり：

「DBを直せばすべて直る」

━━━━━━━━━━━━━━━━━━━━
■ 起動方法
━━━━━━━━━━━━━━━━━━━━

1. 以下フォルダで実行

C:\Users\sr01\Desktop\MACRO\C\BuisinessCard

2. コマンド実行

dotnet run

3. 表示確認

「監視開始」が出ればOK

━━━━━━━━━━━━━━━━━━━━
■ 通常登録（新規名刺）
━━━━━━━━━━━━━━━━━━━━

1. PDFを以下へ入れる

C:\Users\sr01\Desktop\SCAN\BuisinessCard

2. フォーム入力

Category：例）SW / SE / CM / EX
Name　　：例）芳野病院 藤田千尋

3. Enterキーで確定

4. 自動処理

・PDFリネーム＆移動
・Google Driveアップロード
・Supabase登録（メイン）
・CSV追記（ログ）

5. iPhoneで即反映

━━━━━━━━━━━━━━━━━━━━
■ 更新モード（再構築）
━━━━━━━━━━━━━━━━━━━━

用途：

・Supabaseの状態をローカルに反映
・CSVを再生成

手順：

1. フォーム表示時に「更新」ボタンを押す

実行内容：

・Supabase → 全件取得
・CSV完全再生成

※差分更新ではない
※状態の再構築

━━━━━━━━━━━━━━━━━━━━
■ データ削除方法（重要）
━━━━━━━━━━━━━━━━━━━━

【正しい手順】

1. Supabaseで削除
   　テーブル：public.cards
   　対象行を削除

2. 更新モード実行

→ CSV再生成
→ iPhone側にも反映

【やってはいけない】

CSVを削除して更新

→ Supabaseに残っているため復活する

━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━

SCAN\BuisinessCard
　→ 入力（PDF置き場）

Output
　→ CSV（スナップショット）

━━━━━━━━━━━━━━━━━━━━
■ よくあるトラブル
━━━━━━━━━━━━━━━━━━━━

● 反映されない
→ 更新モード実行

● PDFが処理されない
→ コピー途中の可能性 → 再投入

● Drive失敗
→ 通信 or 認証
→ token.json(binとroot)削除後、再実行で復旧可能

● データが消えない
→ Supabaseから削除していない

━━━━━━━━━━━━━━━━━━━━
■ 構造の特徴（重要）
━━━━━━━━━━━━━━━━━━━━

・入力は Category + Name のみ
・カテゴリは自動生成（マスタ不要）
・Supabaseが唯一の正本
・CSVはいつでも再生成可能

つまり：

「入力は最小、構造は自己生成、状態は一意」
